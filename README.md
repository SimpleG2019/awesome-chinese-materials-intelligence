## 🔬 Core Focus Areas
- 🛡️ **High-Entropy Alloys (HEAs)**: Dual-phase microstructures, cryogenic fracture toughness, radiation resistance.
- ✈️ **Aerospace Superalloys & Intermetallics**: Single-crystal nickel-based superalloys, TiAl alloys, thermal barrier coatings.
- ⚡ **Functional Ceramics & 2D Nanomaterials**: MXenes, transition metal dichalcogenides, high-temperature piezoelectrics.
- 🔬 **Additive Manufacturing & Microstructure**: Laser powder bed fusion (LPBF), melt pool dynamics, defect mitigation.
